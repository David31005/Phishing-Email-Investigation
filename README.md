# Phishing Email Investigation | SOC Analyst Portfolio

## Project Overview
This project demonstrates a simulated Security Operations Center (SOC) investigation of a suspected credential-harvesting phishing email.

The investigation focuses on identifying phishing indicators, assessing potential risk, and documenting incident response recommendations.

## Investigation Summary
- Case ID: PHISH-001
- Threat Type: Suspected Credential-Harvesting Phishing
- Risk Assessment: High (Potential Impact)
- Environment: Simulated Training Lab
- Status: Investigation Documentation Completed

## Key Findings
1. The email impersonated an IT support team.
2. The sender domain was not verified as an authorized company domain.
3. The message threatened account disablement within 30 minutes.
4. The email requested password verification through an unverified external login link.
5. The message used urgency and fear to pressure the recipient.

## Investigation Methodology
1. Reviewed the simulated email evidence.
2. Identified suspicious sender and URL indicators.
3. Evaluated social engineering techniques.
4. Documented available evidence and limitations.
5. Developed recommended containment, eradication, and recovery actions.

No live malicious activity, confirmed compromise, or real-world remediation was performed.
